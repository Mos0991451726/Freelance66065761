# 🧾 Freelance Escrow & Smart Payment Platform

**DigitalWork Solutions** — แพลตฟอร์มจ้างงานฟรีแลนซ์และระบบชำระเงินตามผลงานด้วย Smart Contract บน Ethereum

## 🌐 Live Demo

[**คลิกเพื่อเข้าใช้งานเว็บไซต์ Freelance Escrow**]()

## 📌 About The Project

โปรเจกต์นี้เป็นเว็บไซต์ต้นแบบสำหรับระบบจ้างงานฟรีแลนซ์ โดยใช้เทคโนโลยี Blockchain และ Smart Contract บน Ethereum เพื่อช่วยจัดการข้อตกลงระหว่างผู้ว่าจ้างและฟรีแลนซ์ รวมถึงการฝากเงินค่าจ้างและติดตามสถานะของงาน

## ✨ Features

- 🔗 **MetaMask Integration** – เชื่อมต่อกระเป๋าเงินดิจิทัล MetaMask
- 📄 **Create Work Agreement** – สร้างข้อตกลงการจ้างงานระหว่างผู้ว่าจ้างและฟรีแลนซ์
- 💰 **Escrow Payment** – ฝากเงินค่าจ้างผ่าน Smart Contract
- ⛓️ **Ethereum Smart Contract** – ใช้ Smart Contract ในการจัดการธุรกรรม
- 📊 **Transaction Tracking** – ตรวจสอบรายการงานและสถานะธุรกรรม
- 🔄 **Wallet Management** – เชื่อมต่อและเปลี่ยนบัญชี Wallet

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Ethereum Blockchain
- Solidity Smart Contract
- MetaMask
- Remix IDE

## 🚀 Getting Started

1. เปิดเว็บไซต์ผ่าน Live Demo
2. ติดตั้ง MetaMask Extension บน Browser
3. เชื่อมต่อกระเป๋าเงิน MetaMask
4. กรอก Contract Address ที่ได้จากการ Deploy Smart Contract
5. สร้างข้อตกลงการจ้างงาน
6. ฝากเงินเพื่อเริ่มต้นกระบวนการจ้างงาน
